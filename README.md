## Project Description: Basic BMI Calculator
This is a small Python-based project inspired by a short tutorial. I developed this tool to help users calculate their Body Mass Index (BMI) based on their weight and height.

# Key Features
**- User Data Collection:** Prompts users to input their name, weight (in pounds), and height (in inches).

**- Automated Calculation:** Uses the standard formula to provide an accurate BMI score.

**- Health Status Classification:** Based on the calculated BMI, the system automatically categorizes the user into one of the following groups: Underweight, Normal Weight, Overweight, Obese, or Severely Obese.
